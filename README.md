# yt-prime

Ad-free YouTube, on your phone and on your desktop.

Two apps that both wrap the real YouTube web app and apply a
**uBlock-Origin-style ad blocker** (strip ad DOM, block ad networks,
auto-click skip buttons):

| App | Platform | Built with | How to get it |
|-----|----------|------------|---------------|
| **Mobile** | Android 5.0+ | Native Android (Java WebView) | **Download the ready APK** (below) |
| **Desktop** | Windows/Linux | Python — PySide6 QtWebEngine | `pip install -r requirements.txt && python main.py` |

- The **mobile** app is a small native WebView app — no Python runtime, no
  GL dependency — so there is nothing to crash on an old phone. The APK is
  ~40 KB and works on **any Android 5.0+ device** (all ABIs).
- The **desktop** app is pure Python with a phone-sized portrait window.

No Play Store, no root, no account required.

## 📱 Mobile app (Android)

A ~40 KB native app that opens YouTube in a full-screen Android WebView and
blocks ads at two levels — **network** (ad requests are dropped before they
load) and **DOM** (an injected script hides/removes ad elements and
auto-clicks skip buttons).

### In-app menu (top-right ⋮)

- **Refresh** — reload the page.
- **Ad-block: ON/OFF** — toggle the filter (takes effect on reload).
- **Desktop site: ON/OFF** — switch the desktop YouTube layout in the phone.

### How it blocks ads

- **Network:** `shouldInterceptRequest` returns an empty response for
  `doubleclick.net`, `googlesyndication.com`, `googleadservices.com`,
  `adservice.google.com` and in-player video ads
  (`googlevideo.com` URLs with `ad_signature`).
- **DOM:** an injected stylesheet hides every known ad element
  (`ytd-display-ad-renderer`, `ytd-in-feed-ad-layout-renderer`, player
  overlays, masthead/promoted cards…) and a `MutationObserver` + 2 s sweep
  strips ad nodes and **auto-clicks the skip button** for residual ads.
- The content script is idempotent — it installs once per page and is
  re-injected on every page load and every 2 s, so nothing can slip through.

The content script is generated by `mobile/adblock.py` (single source of
truth) and shipped as `mobile/app/src/main/assets/adblock.js`.

### Build it yourself

```bash
# needs JDK 17 + Gradle 8.7
cd mobile
gradle assembleDebug
# APK appears in mobile/app/build/outputs/apk/debug/
```

CI builds the APK on every `v*` tag (`.github/workflows/release.yml`) and
attaches it to a GitHub Release.

## 🖥 Desktop app

A phone-sized portrait window (~430×860, resizable) around the full desktop
YouTube site, with the same ad blocker at the network *and* DOM level.

```bash
cd desktop
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

- **Network blocking** — drops requests to ad networks
  (`doubleclick.net`, `googlesyndication.com`, `googleadservices.com`) and
  kills in-player video ads (`googlevideo.com` URLs with `ad_signature`);
  blocked count + reason shows in the status bar.
- **Cosmetic blocking** — injected stylesheet + MutationObserver removes ad
  elements and auto-clicks skip.
- **Persistent login** — your YouTube account survives restarts.

WSL note: `sudo apt install libxkbfile1`, and if you have no GPU:
`QTWEBENGINE_CHROMIUM_FLAGS="--disable-gpu --no-sandbox"`.
